# 04. 状態推定 (State Estimation)

> アポロ計画の航法誘導、GPS・スマホの位置推定、自動運転のセンサーフュージョンまで — カルマンフィルタは「ノイズだらけの観測から真の状態を知る」ための60年選手。

## 目標

- ノイズを含む観測から状態(角度・角速度・位置など)を推定する
- PRMLの線形動的システム(第13章)がカルマンフィルタそのものであることを実装で確かめる
- MLで実装した「Kalman Filter alpha-beta」が、一般のカルマンフィルタの定常状態(時不変系でのゲイン収束後)の特別な場合であることを確かめる

## 内容

| ファイル | 内容 |
|---|---|
| `01_kalman_filter.py` | 線形化した振り子(状態=角度・角速度)を、角度のみのノイズ付き観測から線形カルマンフィルタで推定。NEES(正規化推定誤差二乗)でフィルタの一貫性を検算 |
| `02_alpha_beta_steady_state.py` | 等速直線運動モデルでカルマンフィルタのゲインが定常値に収束することを示し、その定常ゲインを固定で使うフィルタ(alpha-betaフィルタ)が時変ゲインのカルマンフィルタと一致することを確認 |
| `notes.typ` / [`notes.md`](notes.md) / `notes.pdf` | 予測ステップ・更新ステップ(カルマンゲインの導出、コスト関数最小化による導出)を行列形式で証明。EKFへの一般化、alpha-betaフィルタとの関係も記載。JSKロボティクス研究室のEKF解説(Thrun, Burgard and Fox, *Probabilistic Robotics* 3.3節に基づく)とデータ同化分野のコスト関数導出を参考にした。`notes.md` はPDFのページ画像を埋め込んだGitHub閲覧用 |

## 確認方法

- `01_kalman_filter.py`: 真値(シミュレーターで既知)に対する推定誤差が、推定した共分散 $P$ に見合っているか(NEES: 正規化推定誤差二乗が自由度2のカイ二乗分布の95%区間に収まる割合が理論値95%に近いか)。フィルタ後のRMSEが生の観測より小さいか
- `02_alpha_beta_steady_state.py`: 時変ゲインのカルマンフィルタと、その定常ゲインを固定で使うalpha-betaフィルタが、過渡応答後にほぼ一致するか
- `notes.typ`: 各定理の証明がコード中のどの変数・処理に対応するかをコメントで明記

## 扱っていないこと(発展課題)

- パーティクルフィルタ: ロボットの自己位置推定の定番手法(PRML 13.3.4)
- 多リンクアームなど非線形性の強い系でのEKF実装(現状は振り子の小角近似のみ)
