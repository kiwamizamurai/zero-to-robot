障害物をよけて腕を動かす(RRT-Connect)

腕の前に高さ 60 cm の壁があります。青い玉から壁の向こうの緑の玉へ手を移すとき、どう動けばぶつからないかを、ロボット自身に探させます。腕の姿勢(7 つの関節の角度)を「7 次元の空間の 1 点」と見なして、始まりと終わりの両方から木の枝をランダムに伸ばし、つながったら道が見つかったことになります。枝を伸ばすたびに「この姿勢で壁や床にぶつかる?」を物理エンジン MuJoCo に聞いています。ドラッグで視点を回せます。

スタートを押すと、探索が始まります。
始まりから伸ばす木 終わりから伸ばす木 見つかった道 短くした道 まっすぐ補間した動き 実行した手先の軌跡

    元の Python 版との違い: 始まりと終わりの姿勢を出す逆運動学(手先の位置から関節の角度を逆算する計算)は、Python 版は mink、このブラウザ版は減衰つき最小二乗法です。また、枝の途中で当たり判定をする間隔は、Python 版の 0.03 rad ではなく 0.01 rad にしています(0.03 rad だと壁をかすめる道が出ることがあったため)。乱数も別物なので、同じ seed でも Python 版と同じ道にはなりません。
