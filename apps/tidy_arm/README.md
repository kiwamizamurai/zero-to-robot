# お片付けロボットアーム

机の上のブロックを箱に片付ける 2 関節アームのシミュレーター。証明や数式から入る前に、「ロボットアームが何をしていて、01〜05 の計算がどこで使われているか」を目で見てつかむためのもの。

## シミュレーション

[ブラウザでシミュレーションを動かす](https://kiwamizamurai.github.io/zero-to-robot/tidy_arm/)

ブロックを 1 つずつ見つけて、角度を計算し、つかんで箱へ運ぶ。途中から「ぜんぶ片付ける」で残りもまとめて片付ける。

## このアプリで学べること

- **ロボットアームの仕事の流れ**: 見つける → 角度を計算 → 動かす → つかむ → 運ぶ → はなす。工場のアームも同じ流れ
- **逆運動学**: 「手をここに置きたい」から「関節を何度にするか」を出す計算。スライダーで手を動かす難しさと、ドラッグするだけで角度が決まる便利さを比べると、なぜ要るかが分かる
- **なめらかな動き**: 急に動くと揺れて危ないので、動き出しと止まる瞬間をゆっくりにする(5 次多項式)

**キーワード**: 順運動学・逆運動学、関節空間とタスク空間(手先の空間)、2 リンクアーム、余弦定理、作業領域(届く範囲)、軌道計画、5 次多項式、ピック&プレース

## 動かし方

ブラウザで `index.html` を開くだけ(ビルドもサーバーも不要)。

```bash
xdg-open apps/tidy_arm/index.html   # macOS なら open
```

## 画面の見方

- **左の大きな画面**: 机を横から見たところ。左の黒い台がロボットの土台で、黄色い丸が**モーター(関節)**。根元が「肩」、真ん中が「ひじ」。右の枠が箱
- **関節の横の数字**: いまの肩の角度と、ひじの曲げ角度。ロボットが動かせるのはこの 2 つの数字だけ
- **吹き出し**: ロボットがいま何を考えているか
- **点線の円弧**: 手が届く範囲。これより外には、どう関節を曲げても届かない
- **右の操作盤**: 「おまかせ」と「自分で動かす」を切り替える

## ロボットの頭の中(6 ステップ)

画面の下のカードは、片付け 1 回分の手順。いまやっているステップが青く光る。この 6 ステップは、工場のアームでも手術ロボットでも同じ。

### ① 見つける → ② 角度を計算

上の画面全体の図が、ちょうど ② のところ。吹き出しに「その真上に手を置くには… 肩 112°、ひじを 142° 曲げる」と出ていて、**青い点線のアーム**が、計算で出した姿勢。

- 「手をここに置きたい」から「肩とひじを何度にするか」を出す計算が**逆運動学**(01_kinematics)
- 2 関節なら、余弦定理だけで解ける。このアプリは「ひじを上に出す」ほうの答えを選んでいる(答えはもう 1 つ、ひじを下に出す形もある)

### ③ 動かす → ④ つかむ → ⑤ 運ぶ

赤いブロックをつかんで、箱の上へ運んでいるところ。点線が行き先の姿勢(肩 44°、ひじ 48°)。

- **動き出しと止まる瞬間はゆっくり**: 急に動くと揺れて危ないので、5 次多項式 `10t³ − 15t⁴ + 6t⁵` で速さを決めている(05_planning)
- **真下に降りるときも、角度は毎瞬計算し直す**: 手を「まっすぐ下に」動かすだけでも、肩とひじは両方とも少しずつ違う動きをする。手先の直線を細かく区切って、そのつど逆運動学を解いている

### ⑥ はなす

指を開くと、ブロックは重力で箱の中に落ちる。手を上げてから次のブロックへ向かう。

## おまかせで全部片付ける

「ぜんぶ片付ける」を押すと、4 つのブロックを順番に箱へ積む。ブロックを 1 つクリックすると、それだけ片付ける。「ゆっくり再生」にチェックを入れると、ステップの切り替わりが追いやすい。

## 自分で動かす(いちばん大事なところ)

(シミュレーションを動かすと、片付け終わったあとに「自分で動かす」へ切り替え、手をドラッグしているところ。最初から試すときは「最初に戻す」でブロックを机に戻してから)

1. **まず、スライダーだけでブロックをつかんでみる**: 「肩の角度」と「ひじの曲げ」を動かして、指の間にブロックを入れる。手を真下に動かしたいだけなのに、2 つのスライダーを同時に少しずつ動かさないといけないので、かなり難しい
2. **次に、画面上で手をドラッグする**: 手を置きたい場所を指すだけで、肩とひじの角度が決まり、**右のスライダーが勝手に動く**。手の周りの点線の円は「ここをつかんで動かせる」という印

2 のとき裏でやっているのが、② と同じ逆運動学。人は「手をどこに置きたいか」で考え、ロボットは「関節を何度にするか」で動く。そのあいだをつなぐのがこの計算。

## 中身とリポジトリの対応

| ステップ | このアプリでの実装 | 対応するフェーズ |
|---|---|---|
| 角度を計算 | 2 リンクの逆運動学を余弦定理で解く(ひじを上に出す解) | [`01_kinematics/`](../../01_kinematics/) |
| 動かす | 5 次多項式 `10t³ − 15t⁴ + 6t⁵` で、ゆっくり動き出してゆっくり止まる | [`05_planning/`](../../05_planning/) |
| 真下に降りる | 手先の直線を細かく区切り、各時刻で逆運動学を解き直す | [`05_planning/`](../../05_planning/)(カルテシアン空間軌道) |

動力学(02)と制御(03)は入れていない。関節は計画どおりの角度に正確に動くものとして扱っている(モーターの力や重さの影響は無視)。ブロックの落下だけは簡単な重力で動かしている。モーターの力まで含めると何が起きるかは [`../balance_bot/`](../balance_bot/) で、同じ片付けを本物のアームのモデルでやると何が変わるかは [`../panda_pick_place/`](../panda_pick_place/) で見られる。
