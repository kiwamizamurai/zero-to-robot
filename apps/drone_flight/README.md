# ドローンを飛ばす(Skydio X2 × MuJoCo × カスケード制御)

[ブラウザでシミュレーションを動かす](https://kiwamizamurai.github.io/zero-to-robot/drone_flight/)

空を飛ぶロボット。MuJoCo Menagerie の **Skydio X2**(4 つのプロペラのドローン)を、離陸 → 四角く巡回 → 突風に耐える → 着陸 させる。

ドローンが動かせるのは 4 つのプロペラの推力だけで、**横向きの力を直接は出せない**。横に進みたいときは、まず機体を傾けて推力を斜めに向ける。だから制御を 3 段に重ねる(**カスケード制御**)。

## このアプリで学べること

- **劣駆動(underactuated)**: 動かしたい自由度(位置 3 + 向き 3 = 6)より、操作できるもの(プロペラ 4 つ)が少ない。だから「傾けて進む」という回り道が必要になる
- **カスケード制御**: 外側の遅いループ(位置)が、内側の速いループ(姿勢)に目標を渡す。内側が十分速いことが前提
- **ミキサー**: 「全体の推力と 3 軸のトルク」を、4 つのプロペラの推力に配分する行列
- **外乱に耐える**: 横からの突風を受けても、フィードバックで元の場所に戻る
- **姿勢の制御が弱いと墜落する**: 内側のループがいかに大事か

**キーワード**: ドローン、クアッドコプター、劣駆動、カスケード制御、PID / PD 制御、姿勢制御、推力、ミキサー(制御配分)、回転行列、幾何学的制御(SO(3))、外乱、PX4、ArduPilot

## しくみ(3 段の制御)

```
目標の位置 ──▶ [1. 位置の制御] ──欲しい加速度──▶ [2. 姿勢の制御] ──推力・トルク──▶ [3. ミキサー] ──▶ 4 つのプロペラ
  (5 次多項式)     ゆっくり(PD)                      速い(回転行列の差)              行列の逆
```

1. **位置の制御**: 目標の位置・速度とのずれから、欲しい加速度を決める(PD)。重力を打ち消す分(+9.81 m/s² 上向き)も足す
2. **姿勢の制御**: 機体の「上向き」を欲しい加速度の向きにそろえ、機首を目標の向きに向けるには、どう回せばいいかを決める。ずれは回転行列の差から取り出す
3. **ミキサー**: 4 つのプロペラの位置と、回転の反作用(プロペラが回ると機体は逆向きに回されようとする)から、「推力 f₁〜f₄ → 全体の推力と 3 軸のトルク」の 4×4 行列を作り、その逆行列で配分する

## 結果

| 条件 | 結果 |
|---|---|
| 通常 | 19.5 秒で最後まで飛んで着陸。目標とのずれは平均 3.4 cm |
| 突風(横から 5 N、1 秒間) | 最大 36 cm 流され、機体は最大 38° 傾いたが、数秒で元の場所に戻った |
| 姿勢の制御を 1/10 に弱める | 5.9 秒で墜落 |

## 図の見方

- **左(真上から見た道すじ)**: 灰色の破線が目標、青が実際、赤が突風を受けている間。角はほぼ目標どおりで、ずれるのは辺の途中(道すじが少しうねる)。特に右の辺(x = 1.2)は、向きを 90° 変えながら 0.4 m 上がる区間なので、うねりが大きい
- **右上**: 目標とのずれ [cm] と、機体の傾き [°]。ピンクの帯が突風。突風で大きく傾き、ずれも増えるが、すぐ戻る。巡回中も、加速・減速のたびに傾いている(傾かないと進めないから)
- **右下**: 4 つのプロペラの推力 [N]。ふだんは約 3.25 N ずつ(4 つで機体の重さ 1.3 kg を支える)。向きを変えたり傾けたりするときに、4 つの推力に差がつく。点線は 1 つのプロペラの最大推力(13 N)

## 動画の要所(Python 版が書き出すもの)

動画と図は、Python 版のスクリプトを動かすと `output/` に書き出される(リポジトリが重くならないよう、コミットしていない)。ブラウザ版では、同じ様子を画面でそのまま見られる。

| コマ | 何をしているか |
|---|---|
| 左上 | 離陸して 1 m の高さへ。傾き 0° で、まっすぐ上がる |
| 右上 | 巡回中。オレンジの玉が巡回する点。進むために少し傾いている |
| 左下 | 突風(`GUST!`)を受けて、32° 傾き、29 cm 流されたところ。すぐに押し返す |
| 右下 | 戻って着陸する直前。ずれ 0.4 cm |

### 姿勢の制御を弱めると

内側の姿勢の制御を 1/10 に弱めると、機体を狙った角度に傾けるのが間に合わず、傾きすぎては戻しすぎて、揺れが大きくなって墜落する。**カスケード制御では、内側のループが外側より十分速くないといけない**。本物のドローンの制御ソフト(PX4 や ArduPilot)も、同じように位置 → 速度 → 姿勢 → 角速度 → モーター、と何段にも重ねている。

## ブラウザ版と Python 版の違い

- 制御(位置 → 速度 → 傾きの 3 段、4×4 のミキサー)・ゲイン・飛行ルート・墜落の判定は Python 版と同じ。数値もほぼ同じ(平均のずれ 3.4 cm、最大 36 cm、突風で最大 38°傾く、姿勢制御を弱くすると 5.9 秒で墜落)。
- 機体のモデルは、見た目のテクスチャを省いた軽量版(約 0.5 MB)。固定視点と、機体を追う視点を切り替えられる。
- 突風は、ルートの途中(14〜15 秒)の自動の 1 回に加えて、好きな向きで足すボタンを付けた(Python 版にはない)。
