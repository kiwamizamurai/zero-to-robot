# 02. 動力学 (Dynamics)

> ヒューマノイドの二足歩行、ゲームエンジンの物理演算、車の乗り心地シミュレーションまで — 「力と運動の関係」のモデルなしに、まともな制御もシミュレーションもできない。

## 目標

- 時間発展するシステム(振り子・2関節アーム)をフロムスクラッチで数値積分する
- 数値積分法の選び方が結果を左右することを体感する(エネルギー保存で検算)
- 多リンクアームの運動方程式をラグランジュ力学から導出する(`01_kinematics`と同じ2関節平面アームを使用)

## 内容

| ファイル | 内容 |
|---|---|
| `01_pendulum_simulation.py` | 振り子のシミュレーション。素朴なオイラー法(両方の更新式を同じ古い状態から計算)と半陰的/シンプレクティック オイラー法(片方に更新済みの値を使う)を比較 |
| `02_two_link_dynamics.py` | `01_kinematics`と同じ2関節平面アームに質量・慣性を持たせ、運動方程式 $M(\theta)\ddot\theta + c(\theta,\dot\theta) + g(\theta) = \tau$ をラグランジュ形式で実装。有限差分によるラグランジュ方程式との一致、自由運動でのエネルギー保存、順動力学↔逆動力学の往復を検算 |
| `notes.typ` / [`notes.md`](notes.md) / `notes.pdf` | `02_two_link_dynamics.py` の数式的裏付け。各リンク重心の速度→運動エネルギー・位置エネルギー→ラグランジュ方程式による運動方程式の導出を行間なく証明する(Asada, MIT 2.12 OCW 第7章に基づく) |

## 確認方法

- `01_pendulum_simulation.py`: 摩擦・外力なしでエネルギーが保存されるか(`output/01_pendulum_energy.png`)。素朴なオイラー法はエネルギーが単調に増加し、半陰的オイラー法はほぼ一定に保たれることを確認(積分法の落とし穴)
- `02_two_link_dynamics.py`: 逆動力学(解析式)が、ラグランジアン$L=T-U$のみから計算した有限差分と一致するか。自由運動でエネルギー$T+U$が保存されるか(`output/02_two_link_energy.png`)。順動力学→逆動力学が恒等写像になるか
- `notes.typ`: 各定理の証明がコード中のどの関数に対応するかをコメントで明記

## 扱っていないこと(発展課題)

- ラグランジュ力学とニュートン・オイラー法(Asadaの原著で同じ結果を与えることは示されているが、本リポジトリでは未実装)との数値的な照合
- ルンゲ＝クッタ法など、RK4以外の高次の数値積分器との比較
- 一般の$n$自由度アームへの一般化(参考: Featherstone, *Rigid Body Dynamics Algorithms*, 2008 — 多体動力学アルゴリズムの標準文献)
